## Overview

`Tabs` is a thin composition layer over Radix UI's Tabs primitive. It
exports the four pieces you need — `Tabs`, `TabsList`, `TabsTrigger`,
`TabsContent` — with shadcn-compatible styling wired in. Because it's
Radix underneath, keyboard support, focus management, and WAI-ARIA
semantics come for free.

## Accessibility

- Arrow keys move focus between triggers; Home/End jump to the first/last.
- `activationMode="manual"` is the right choice when tab panels are heavy
  or fetch remote data — focus moves without activating until the user
  presses Enter/Space.
- Each `TabsTrigger` / `TabsContent` pair must share a unique `value`
  string; Radix wires aria-controls and aria-labelledby accordingly.

## Notes

- Use `orientation="vertical"` when rendering a sidebar-style tab list;
  remember to update the visual layout to match.
- For deeply nested surfaces (tabs inside modals inside tabs), give the
  inner tabs an explicit `defaultValue` to avoid ambiguity with the outer
  Radix context.

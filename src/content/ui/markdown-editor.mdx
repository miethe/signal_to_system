## Overview

`MarkdownEditor` is a thin wrapper around CodeMirror 6 tuned for markdown
authoring. It ships with sensible defaults — markdown syntax highlighting,
standard keymaps, a system-aware theme — and keeps its surface area small
(four props) so it composes cleanly with your own toolbar, preview pane, or
split-view layout.

## Usage

The demo uses `client:only="react"` so CodeMirror only loads in the browser.
This keeps the static build fast and defers the CodeMirror bundle until the
user actually scrolls the demo into view.

## Accessibility

- Wraps CodeMirror's textarea-backed editor, which supports standard
  screen-reader navigation and selection announcements.
- Theme follows the system color scheme; combine with your app's `.dark`
  class to drive dark mode explicitly.
- `readOnly` disables editing while preserving caret navigation, so screen
  readers can still read the document.

## Notes

- The editor is **uncontrolled** — changing `initialContent` after mount does
  not replace the buffer. Keep the canonical value in your own state via
  `onChange`.
- Lazy-load this component via `client:visible` in Astro or a dynamic import
  in other frameworks to keep CodeMirror out of the initial JS payload.

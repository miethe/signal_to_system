## Overview

`FileTree` renders a recursive, accessible tree of files and directories. It is
built around the WAI-ARIA tree pattern with roving tabindex, so screen readers
and keyboard users get the same semantics as sighted mouse users. Selection and
expansion state are fully controlled by the parent, which makes it easy to wire
into any content-viewer backend.

## Accessibility

`FileTree` implements the ARIA `tree` pattern:

- **Keyboard**: Arrow keys move focus between visible items; Right expands a
  collapsed folder; Left collapses an expanded folder or moves to the parent;
  Enter/Space selects a file or toggles a folder; Home/End jump to the first or
  last visible item.
- **Roving tabindex**: only the currently focused item is in the tab order, so
  Tab never traps users inside the tree.
- **Labels**: pass a descriptive `ariaLabel` (default `"File browser"`) to
  differentiate multiple trees on the same page.

## Notes

- The tree is fully controlled — keep `selectedPath` and expansion state in
  your own store if you need persistence.
- Use `readOnly` when surfacing content viewers that should not mutate the
  tree (e.g. marketplace previews).
- Omit `onAddFile` / `onDeleteFile` to hide their respective affordances.

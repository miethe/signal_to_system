## Overview

`DiffViewer` renders a side-by-side view of one or more file diffs. Each diff
carries a path, a status (`added` | `modified` | `deleted` | `unchanged`), and
an optional unified-diff string. The component is presentational — wire
`onResolve` to plug it into a sync-conflict or review workflow.

## Accessibility

- Panel headers are semantic headings inside each side so screen readers can
  navigate between left/right regions.
- Resolution buttons (when `showResolutionActions` is true) expose descriptive
  labels via `localLabel` / `remoteLabel` — override these to match your
  domain language.
- `isLoading` and `isResolving` states are announced via aria-live so users
  hear that work is in flight.

## Notes

- Unified-diff strings follow standard `@@ … @@` hunk syntax; the component
  does not itself compute diffs.
- Pair with `tierContext` in enterprise surfaces to replace the plain
  left/right labels with tier badges.

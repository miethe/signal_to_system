## Overview

`StatusBadge` is a small convenience wrapper on top of `Badge`. It takes a
status string and resolves it to a Badge variant through a configurable
color map, so a single status field can drive consistent badges across
different surfaces (tables, detail headers, cards) without scattering
variant logic.

## Accessibility

- Renders as a `<div role="status">` via the underlying Badge, exposing the
  status text directly to assistive tech.
- Because the badge is text-first, color is not the sole carrier of status
  information.

## Notes

- Unknown status values fall back to the `outline` variant — safe default
  for surfacing unexpected data from an API without a UI crash.
- The `statusColorMap` is merged over the built-in defaults, so you only
  need to list overrides rather than repeating the whole map.

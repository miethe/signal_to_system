## Overview

`FrontmatterDisplay` renders parsed YAML frontmatter as collapsible key-value
rows. It handles the three shapes you actually see in practice: scalars,
arrays (rendered comma-separated), and one level of nested objects (rendered
as indented sub-rows). Anything deeper collapses to the raw JSON string — if
you need arbitrarily deep rendering, pair this with your own recursive
component.

## Accessibility

- The expand/collapse control is a `<button>` with an `aria-expanded` state
  so assistive tech announces the open/closed state correctly.
- Key-value rows use a description list internally, preserving semantic
  associations between keys and values.

## Notes

- The component does **not** parse YAML — pass an already-parsed object.
  Reach for `parseFrontmatter` from `@miethe/ui/utils` for a lightweight
  parser if you don't already have one.
- `defaultCollapsed` only seeds the initial state; the user can always toggle
  at runtime.

## Part A — Exploration AAR (complete, 2026-07-02)

Turn the deferred M6 design spec (`design-specs/intenttree-m6-abstraction-engine.md`, `maturity: shaping`)
into a **go/no-go/conditional** verdict *before* authoring a Tier-3 PRD. The spec self-gated as "SPIKE
before PRD," carried 4 unresolved architectural OQs (OQ-1a–d), and named an unmet M4 prerequisite. The
request arrived as `/plan:plan-feature intenttree-m6-abstraction-engine.md commit to main when done.`

### A3. The verdict and why

**CONDITIONAL (confidence 0.8).** The exploration *succeeded at its job*: it resolved every SPIKE-before-PRD
open question and confirmed technical feasibility — but it **withheld commitment** because the value floor
is unmeasured.

- **Feasible** — tech 0.78 (feasible-with-constraints), risk 0.85 (completeness). Not no-go.
- **OQs resolved** (now locked in the proposed ADR):
  - **OQ-1a** — provider = OpenAI `text-embedding-3-small` v1 + sentence-transformers SBERT fallback.
    **Anthropic ships no embeddings API** — the design spec's "Anthropic text-embedding-3" was an error.
  - **OQ-1b** — reuse precedent comes from the **node graph**, *not* the `Artifact` table (`Artifact.body`
    is not populated by the decompose path). This corrects the design spec's stated assumption.
  - **OQ-1c** — parallel **`POST /nodes/{id}/abstract`** + a new `NodeOperation` enum; leave `/decompose`
    untouched (it has 5 live consumers; extending its union buys nothing).
  - **OQ-1d / M4** — deliverable in a **bounded first phase** using **LLM-judged** detection; embedding-
    similarity detection would make M4 a separate epic (defer pgvector).
- **Withheld** — value leg 0.35: no telemetry, single-user + external-agent base, and the project's own
  docs frame M6 as *enhancement, not value floor* (Promotion Trigger #3 explicitly unmet). The deal-killer
  did **not** fire (uplift is *unmeasured*, not *disproven*), but there is no justification to commit a
  13+ pt build on an untested hypothesis.

**Precondition to re-enter** (DI-235): instrument decompose quality → demonstrate plain-context decompose
is measurably insufficient → then `/plan:plan-feature --tier=3` sequencing M4 LLM-judged detection first,
before any pgvector work.

### A4. What went well

- **Phase 0 caught the self-gate cheaply.** A ~2-probe code check (not a deep read) confirmed the unmet
  prerequisite and prevented a premature PRD over 4 unresolved architectural decisions.
- **Parallel legs delivered independent verification, not echo.** The tech leg *corrected the design spec*
  twice (Artifact-table assumption; Anthropic-embeddings error) — first-hand evidence Opus would not have
  surfaced from the spec alone.
- **The low-confidence value leg was the decisive input.** Honoring an honest 0.35 (rather than
  manufacturing demand evidence) is exactly what turned a superficially "feasible → go" into the correct
  "feasible-but-defer."
- **Settled ground is now settled.** The proposed ADR + resolved OQs mean re-entry won't re-litigate the
  provider/API decisions — the exploration's durable payoff even though the verdict was defer.

### A5. What was noisy / to watch

- **Concurrent agents on the shared checkout.** During the run, another agent committed
  `328c74e feat(node): route template + agent decompose through the shared LLM core` and advanced `main`
  past this commit; a transient unstaged `services/node.py` diff appeared mid-run. It was *not* a Mode-B
  violation by the exploration legs (confirmed). **Lesson**: on a shared checkout, stage explicit paths
  only, verify `merge-base --is-ancestor` for your own commit, and don't be alarmed by foreign diffs —
  but *do* verify provenance before touching them.
- **Charter linter reformatting.** `manage-exploration-status.py` re-emits YAML (block scalars, list
  reflow) and `update-field.py` couldn't detect `doc_type: exploration_charter` — `output_artifacts` was
  set via a direct `Edit` instead. Minor; note for tooling.

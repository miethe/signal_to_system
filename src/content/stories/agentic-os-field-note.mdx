## What went well

1. **Human gates as run-record state.** Every gate got a needs-input with the decision framed +
   evidence attached, and a verbatim-quote decision record on clearance. The owner's one-line
   replies ("go on pricing and defer the on-device runs…", "approve and complete") each resolved
   multiple bundled decisions cleanly. Zero gate was self-cleared.
2. **Adversarial review at seal earned its cost.** Codex gpt-5.6-terra (xhigh) found a REAL
   major availability bug the 500+-test suite missed: auth rejection between idempotency
   `reserve()` and `finalize()` permanently wedged the key (and `/jobs` had shipped the same flaw
   as a "documented known limitation" two phases earlier). Fixed, regression-tested both routers,
   live-proven (403 → same-key retry → 201).
3. **Live-verify discipline caught what unit tests structurally cannot** — three times: unwired
   production transport + dev-only httpx (P4), dev-seed missing precompute scope (P5), and the
   relax_global starvation hang only manifesting on the deployed default profile.
4. **Fixtures that state what consumers may conclude.** P1-T8's `intentionally_invalid` manifest
   clause is what made the P3 golden-05 misinterpretation catchable two phases later.
5. **Honest-disclosure culture worked end-to-end**: executors flagged deviations instead of
   silently absorbing them (P5-T4 prices-stay-server-internal scope call), the validator
   correctly ruled "transparent workaround ≠ criterion met" (P5 golden round-trips), karen
   caught "true on disk, false in committed history" at the last mile.
6. **Delegation routing**: Sonnet legs for implementation, codex for AC-validation/adversarial
   (inlined sources per code-mode-host gotcha), orchestrator kept the spine + re-ran all gates
   centrally. The false "ruff clean" claim (1 F401 remaining) re-confirmed why central gate
   re-runs are non-negotiable.

## What went wrong / lessons (themed, with repeat-counts)

1. **Data-quality vs policy failure conflation (REPEAT — 2nd occurrence project-wide).**
   Golden-05: a validator failed whole jobs on legitimate-but-degraded input; same shape as the
   PR #44 missing_closure lesson. Durable rule: *a validation rule that can fire on legitimate
   user data must DEMOTE TRUST, not BLOCK THE IMPORT; "fail closed" is for policy boundaries
   (residency/retention/consent), not data-quality findings.* → promote to a rule/skill.
2. **Deploy-only gap class (3 occurrences).** Unit tests can't see provisioning/composition:
   live transport wiring, dependency groups, dev-seed scopes, config-dependent solver paths.
   → Follow-up: deploy-time scope-vs-routes smoke in the systemd unit's ExecStartPost.
3. **Progress-file drift vs plan folds (every early phase).** Plan-fold commits must sweep
   progress files; the phase/plan file is authority on conflict.
4. **Visual-evidence ACs without a harness (2 occurrences).** P2 carried AC-P2.1 as `partial`;
   P5 validator demanded screenshots late. Don't write ACs requiring evidence the toolchain
   can't capture — or build the harness in the same phase (P5's test-hook screenshot approach
   works and is reusable).
5. **False-green failure modes.** `TEST_RUNNER_*` env-not-args (suites skip, xcodebuild still
   prints SUCCEEDED — verify per-test ✔); background-review verdicts lost to compaction unless
   the log path is persisted to disk in-session (`current-log-path.txt` breadcrumb saved the
   codex verdict this run).
6. **Mode-E reviewer git-write incident (P1, fixed thereafter).** Reviewer prompts must forbid
   git write-commands explicitly, not just "no edits" — prohibition held for the rest of the
   plan (zero further incidents).
7. **Tooling seams in artifact-tracking** (recurring friction): status-enum disagreement
   (`at_risk` written but schema-invalid), `pr_refs=#N` YAML-comment trap (quote it), date
   fields need quoted strings, `--set` batch rolls back wholesale on one bad value,
   update-status recalcs phase status from task counts (can flip a phase early), verified_by
   demanded at completion-time. → Candidate: harmonize the scripts' schema in the upstream skill.
8. **Verify reviewer mechanism claims against code.** Codex's major finding was real but its
   500-assert mechanism was wrong (actual: permanent 409 wedge) — reading `reserve()`'s branches
   changed the regression test that got written. Findings are leads, not verdicts.
9. **rsync'ing a deploy context needs the layout contract stated somewhere.** The build context
   (server/ as subdir + contract fixtures) was rediscovered by failure; it's now in the memory
   file and this AAR.

## Verdict

non-homelab endpoint, free tier provably byte-identical), every human gate recorded, and the

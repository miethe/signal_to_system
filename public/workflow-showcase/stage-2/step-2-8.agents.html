agents · Scripts for bookkeeping

When not to use an agent

Rule of thumb
  Use agents for judgment. Use scripts for bookkeeping.
  If the operation is deterministic, it does not need a model.

Replaced by scripts (per-call cost)
  update-status.py             ~50 tokens   (vs ~25,000 via agent)
  update-batch.py              ~80 tokens
  validate-phase-completion.py ~60 tokens
  query_artifacts.py           ~40 tokens

At 175+ active progress folders, this is the difference
between economically viable and not.

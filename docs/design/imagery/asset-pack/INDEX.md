# External designer asset pack

Copied reference material for external image designers and generators. This is a handoff snapshot, not a runtime asset directory.

## Use order

1. Registry Wave raster plates and hero are the essay-image style authority.
2. Brand authority: primary lockup = waveform-diamond; favicon = waveform bars; secondary = S/S monogram. Do not substitute the constellation reserve mark.
3. Token references describe implementation context only. Dark imagery accent-1 is decided by design-language package.
4. Behavior-only materials show layout or product behavior only; do not imitate them as image style.

## Completeness and size policy

- Copied from the 2026-09-22 v2 visual handoff and the current repository/committed v2 sources.
- Brand provenance: PR #147 (8da1cd6) and PR #148 (b94a2a1).
- No requested copied source file exceeded 10 MB; there are no referenced-not-copied entries.
- Any future source over 10 MB must be listed here with its origin, not copied.

Current hero `hero-02-missing-layer.jpeg`, `diagram-four-failures.jpeg`, `diagram-transitions.jpeg`, and `hero-03-swarm-gate.jpeg` cover the argument but combine metaphorical hero treatments and diagrams. ## Boards

### productivity-hero-control-gap
- **Class:** hero. **Placement:** frontispiece, replacing `hero-02-missing-layer.jpeg`; anchor: “The Productivity Paradox”. **Purpose:** show that capability without governance creates a control gap.
- **EXACT ON-IMAGE TEXT:** `CAPABILITY` · `CONTROL` · `THE MISSING LAYER`.
- **Composition / positioning:** dark field; two stable systems masses left/right labelled capability and control; a luminous but incomplete bridge between them; `THE MISSING LAYER` sits over the gap.
- **Layout:** `[CAPABILITY] ══ broken bridge ══ [CONTROL]`, with title over interruption.
- **Scheme / variant / master:** signal-dark / single / 2400×1350 (16:9).
- **Alt:** Capability and control sit on opposite sides of an incomplete luminous bridge.
- **Caption:** More autonomous capability does not supply its own control plane.
- **Generator prompt:** spacious Registry Wave dark conceptual hero, governed-systems geometry, one broken connection, restrained role-slot glow.
- **Negative prompt:** robots, factories, people, sci-fi cityscape, generic warning icons.
- **Acceptance checks:** gap reads before detail; labels legible; no claim of failure or solution beyond the thesis.

### productivity-four-failures
- **Class:** figure. **Placement:** after “Four failures”; anchor: “The failures are structural.” **Purpose:** distinguish four recurring governance failures without turning them into a checklist.
- **EXACT ON-IMAGE TEXT:** `FOUR STRUCTURAL FAILURES` · `Unbounded work` · `Unclear authority` · `Unverifiable output` · `Unmanaged drift`.
- **Composition / positioning:** four equal cards in 2×2 grid; each has a compact failure-state glyph and one downstream consequence connector converging on a muted `delivery risk` footer.
- **Layout:** `[Unbounded work] [Unclear authority]` / `[Unverifiable output] [Unmanaged drift]` → `delivery risk`.
- **Scheme / variant / master:** paper-light / dark+light pair / 2000×1125 (16:9).
- **Alt:** Four labelled cards identify unbounded work, unclear authority, unverifiable output, and unmanaged drift.
- **Caption:** The paradox is a set of missing operating constraints, not a model-quality problem.
- **Generator prompt:** Registry Wave technical comparison plate, balanced cards, thin rules, restrained accent allocation.
- **Negative prompt:** traffic-light scoring, generic warning triangles, dense prose.
- **Acceptance checks:** all four labels exact; equal conceptual weight; footer does not imply causal measurement.

### productivity-governance-transition
- **Class:** figure. **Placement:** after “A governed transition”; anchor: “Governance changes the shape of the work.” **Purpose:** make the shift from isolated output to governed delivery visible.
- **EXACT ON-IMAGE TEXT:** `PROMPT → OUTPUT` · `INTENT → CONTRACT → EVIDENCE → OUTCOME` · `governed transition`.
- **Composition / positioning:** a thin, faded direct path at top; bright four-stage artifact path below; explicit vertical comparison rule.
- **Layout:** `PROMPT → OUTPUT` above `INTENT → CONTRACT → EVIDENCE → OUTCOME`.
- **Scheme / variant / master:** paper-light / single / 2000×1125 (16:9).
- **Alt:** A direct prompt-to-output path is contrasted with an intent-to-outcome governed path.
- **Caption:** Governance inserts inspectable commitments between request and result.
- **Generator prompt:** minimalist Registry Wave before-and-after flow, one faded path and one governed path, exact labels.
- **Negative prompt:** process clip art, product screenshots, excessive arrows.
- **Acceptance checks:** comparison legible in three seconds; lower path has four discrete stages; direction unmistakable.

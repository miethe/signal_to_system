# Registry Wave visual reference

**Reviewed authority:** the Registry Wave hero, incident-resolution flow, drift-across-five-days graphic, and `diagram-registry-control-plane.svg`, plus the richer Registry Wave v2 asset inventory.

## Observed language

The dark hero is a spacious conceptual systems image: one luminous governed object, a sparse network field, and generous negative space. It states an argument rather than depicting a product. The explanatory work switches to paper-light, print-like technical plates. The control-plane plate has a sentence headline, balanced rounded panels, thin rules, low node count, explicit operational labels, and one restrained semantic accent per concept. Incident and drift pieces make sequence and time inspectable with ordered states rather than decoration.

## Direction for every board

Use one legible claim per image. Name evidence objects and state transitions. Make connectors directional and meaningful. Prefer records, states, gates, timelines, and artifact paths over people, robots, stock photography, or dashboard chrome. Heroes are atmospheric and dark (`signal-dark`); explanatory figures default to `paper-light`, including in a dark essay. Captions should advance the argument, not restate the title.

## Token slots only

Do not invent final hex values or typography. Consume semantic roles from `src/styles/tokens/observatory.css`: `--s2s-canvas`, `--s2s-ink`, `--s2s-ink-muted`, `--s2s-accent`, `--s2s-secondary`, and `--s2s-viz-*`. Refer to them in handoff as canvas, ink, muted, accent-1, accent-2, accent-3, warning, and rule. `src/styles/tokens/bridge.css` confirms new work uses `--s2s-*` directly. Final palette/type values arrive with the design-language package.

## 1. Recipients and order
**Pack A — design language — goes first.** Complete it and return its token package before Pack B creates final art. Pack B may work beforehand only on drafts/compositions with role-name colors; it must not choose final color values or finalize signal-dark art.

## 3. Deliberately not handed off
- `REVIEW-opus-taste-pass.md`, `_briefs/`, agent-process notes, and review internals are excluded.
- Nick-only decisions are resolved here as rules: preserve the five classes and two schemes; paper-light figures stay matted; essay/series heroes require matched dark+light pairs; heroes/social art bake no text; green=ok, red=failed, amber/copper=pending, grey=inactive; Registry Wave PNG plates/hero are the essay-image style exemplar; v2 mockups do not replace that exemplar.
- Existing asset-pack behavior-only prototype/design-board materials are excluded.

## 4. Return contracts
**A returns:** a token package filling every slot in standards §6 for `signal-dark` and `paper-light`, including shared type/stroke/motif/night-twin/surface definitions, reference motif renders for each scheme, and the deferred dark-mode image `accent-1`.
**B returns:** final files named precisely per `essay-storyboards-v1/manifest.yaml`, and a filled manifest status column for every asset (including delivered filenames and notes), with model/seed/exact prompt metadata.

## 5. How the packs join
Role-slot names are the join key. A supplies named roles; B uses those names in boards/prompts and maps final values only after A returns. Do not create a second role vocabulary or substitute raw current-site hex values.

## Verification
`FILE-INVENTORY.txt` in each pack is the authoritative machine-checkable file list. The build verification checks every table path exists in the stated pack.

# S2S v2 visual source — the design authority

**Rule:** this folder (the "visual pack", mirrored from
`signal-to-system-visual-handoff-v2`) is the **visual design authority** for S2S v2. Its 10 page
mockups and 4 asset sheets set palette, type, layout, brand marks and iconography.

The separate build-handoff's prototype/design-board material (`approved-prototype.html`,
`approved-design-board.jpg`, `design/*.png`, `initial-language-skill/*.tokens.json`, and the
Observatory/Folio/Instrument three-language system and orbit/trail header mark it describes) is
**behavior and contract reference only** — interaction patterns, DTO shapes, build tooling — and
is **not** a visual source. Where the two disagree on look, the mockups here win. (Re-anchored
2026-09-22; see `docs/project_plans/s2s-v2/00-adoption-plan.md` "Visual authority" section.)

Not included: `05-prior-handoffs/` (the old build-handoff zips/HTML/md, kept out of the repo —
tracked and available at the visual-pack mirror path recorded in the adoption plan, not committed
here since it duplicates content already in this repo's `analysis/01-build-handoff-digest.md`).

## Primary brand marks (from `02-visual-assets-transparent/signal_to_system_logo_exploration_board.png`)

- **Primary lockup:** "01 Primary Lockup" — waveform-diamond icon + serif wordmark.
- **Favicon:** "Favicon ideas" strip, icon 01 — waveform bars.
- **Secondary mark:** "05 Monogram" — S/S with slash + sparkle.
- Alternates not promoted: "02 Observatory Lockup" (dome-on-mountain), "03 Constellation Lockup"
  (node/line network), "04 Compass Lockup" (star compass).

# Public-Safe Feature List

Use these as public-safe descriptions for SkillMeat in this essay family.

- SkillMeat started as a local skill manager for reusable agent capabilities.
- It evolved into a reference implementation for treating agent capabilities as supply-chain artifacts.
- It manages reusable agentic artifacts across projects, teams, and runtimes.
- Public-safe artifact scope includes skills, commands, agents, hooks, MCP servers, bundles, workflows, context entities, and plugins.
- Public-safe lifecycle scope includes source acquisition, import, curation, registry records, deployment, versioning, provenance, and evidence.
- Import/discovery can be described as GitHub/local artifact acquisition with pinned source identity.
- Deployment can be described as materializing curated artifacts into project/runtime surfaces.
- Governance/provenance can be described as immutable versions, content hashes, audit trail, signed bundles, BOMs, attestations, and trust policy.
- Context packaging can be described as treating reusable project/domain context as a managed artifact class.
- Enterprise direction should be framed as validation-gated or controlled-pilot direction, not broad production SaaS.

Safe one-sentence version:

> SkillMeat started as a local skill manager and evolved into a reference implementation for treating agent capabilities as supply-chain artifacts: acquired from sources, curated in collections, materialized into runtimes, and governed with provenance, policy, and evidence.

# Do Not Disclose

Keep the public essay at the thesis and architecture-pattern level. Avoid anything that reads like implementation disclosure, patent claims, internal architecture notes, or operational exposure.

## Keep Abstract

- Exact schemas for SkillBOM, AAX, AAMP, context packs, import plans, evidence models, or related formats.
- Detailed import normalization mechanics.
- Target-aware mapping behavior and cross-runtime overlay internals.
- Discovery/ranking heuristics and trust scoring internals.
- Context selection algorithms, token budgeting mechanics, and provider-routing logic.
- Scoring, certification, revocation, replay, or policy derivation algorithms.
- Internal APIs, route designs, endpoint paths, code architecture, repository interfaces, database models, or migration names.
- Signing/key-management implementation details, secret handling, key storage, planned HSM/KMS mechanics, or PAT workflows.
- Security bugs, route gaps, stale remote-node details, internal hostnames/IPs, and remediation specifics.
- Portable context-pack resolution mechanics, write-authority chokepoints, reconciliation invariants, and artifact graph algorithms.

## Avoid Claims

- SkillMeat invented skills registries.
- Vendors copied SkillMeat.
- GitHub, JFrog, Red Hat, or MCP efforts are incomplete and therefore irrelevant.
- GitHub `gh skill` is a vetted marketplace.
- The official MCP Registry hosts, certifies, or scans MCP server code.
- Red Hat OpenShift AI MCP Catalog is a settled GA production supply-chain platform where Red Hat marks components as preview.
- JFrog scanning/signing/access-control guarantees apply without product configuration, entitlement, and policy context.
- SkillMeat has anonymous public marketplace downloads, one-click public pack install, or broad multi-tenant production readiness unless current public docs support it.

# Claims To Avoid

- "Nobody else saw this."
- "SkillMeat invented skills registries."
- "Vendor X copied my idea."
- "These tools are incomplete, so they do not matter."
- "GitHub certifies skills."
- "`gh skill` is a secure marketplace."
- "The official MCP Registry scans or hosts server code."
- "Red Hat OpenShift AI MCP Catalog is fully production-ready" without preview qualifiers.
- "JFrog guarantees every skill is scanned/signed/safe" without configuration and entitlement context.
- "The agent skills ecosystem has a universal attack rate of X%" based on a single study sample.
- "SkillMeat is a full public marketplace" unless public docs and running product surfaces support that claim.
- "SkillMeat is a complete enterprise SaaS" unless public docs and deployment evidence support that claim.
- Any exact implementation claim involving schemas, route internals, import planning, scoring, policy derivation, replay, or provenance graph algorithms.

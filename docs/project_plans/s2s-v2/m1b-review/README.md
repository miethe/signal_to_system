# M1b review set

Captured with `scripts/capture-review.py` (Chromium, device scale 1, dark unless named `light`),
then converted to WebP. The 390px essay capture is cropped to its first 6000px.

| File | What it compares |
|---|---|
| `sbs-home.webp` | Home mockup vs build, 1448 viewport |
| `sbs-about.webp` | About mockup vs build, 1448 viewport |
| `sbs-essay.webp` | Live essay (the pre-v2 reader, unchanged until M2) vs the v2 article proposal at `/studio/templates/article/`. There is no essay mockup. |
| `sbs-mobile.webp` | Desktop mockups for scale beside Home, About and an essay at 390 |
| `full-*-1448.webp` | Full-page Home and About |
| `*-390.webp`, `*-1448.webp` | 404, series, tag, states, studio language control, light-theme Home and About |

## M1 — Vertical slice (private). *The handoff's first milestone.*

Import one real packet → resolve its source/claim references through Foundry → one bounded
deterministic check → one **private** S2S preview with a correct evidence trail.

- **Packet:** Machine Continuity / *What Survives the Copy?* (`evidence/imported/SYNTHESIS.md`,
  `continuity-sources.md`, captions, motif preview), the handoff's own first-slice choice
  (S2S_LABS §8; INDEX: clearest recovered package). Toy-vs-real-agent scope stays explicit; no new
  experimental validation is claimed. The motif HTML is untrusted data and is never executed.
- **Deterministic check:** a Lab-authored, bounded computation of the typed-succession motif —
  a synthetic lineage (fork, divergence, merge) with shared-ancestor evidence, comparing naive
  evidence merge (double counts) with source-aware merge (counts shared origin once). Fixed inputs
  → byte-identical output → digest-bound attempt receipt. It checks a *stated mechanism*, not a
  claim about agents.
- **Foundry:** a **local file-backed RF workspace** inside the private Lab workspace (`rf init`),
  the synthesis imported through `rf intake external-report` (non-authoritative
  `platform_synthesis`), sources recorded at their true access depth (locator-only where bytes
  were not retrieved). Node RF is read-only in M1 (GET). No node writes.
- **Preview:** release candidate built to the 04 layout; the S2S M3a gate (with M1d's additive
  lab kinds) run against it: it must **fail closed** without a Nick receipt, and pass only in a
  test fixture explicitly marked `fixture_only`. The human-readable preview is an unstyled static
  render of the report + evidence trail generated by the Lab — **not** an S2S page (Labs UI is the
  visual lane, M4).
